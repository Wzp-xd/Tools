# sprite-gen 更新日志

## 2026-06-22

- 新增非角色的「普通序列帧」类型，并按类型分流走各自流程(旧版只支持角色)
- 新增精灵级清单配置 sprite.json，作为抽象入口汇总所有动画
- 新增「展开更多选项」，可查看并调整全部参数
- 重构 sheet 动画配置格式，从原本 Aseprite 风格改为 Pixi.js 的帧名列表风格
- 修复 K 帧模式，现在能正确按关键帧抽帧、保留原节奏(精灵表更小)
- 拆帧/抠图的中间文件成功导出后自动清理(旧版会残留)
- 生成视频默认使用 seedance 的 fast 模式，更快更省 token
- 交互流程优化:增强审核流程、新开会话门禁、进度记录细化等
