# 试管排序 - 游戏策划文档

## 1. 游戏概述

| 项目 | 说明 |
|------|------|
| 游戏名称 | 试管排序（Water Sort） |
| 游戏类型 | 益智 / 休闲 |
| 核心玩法 | 将不同颜色的液体在试管间倒来倒去，使每根试管内只含同一颜色 |
| 屏幕方向 | 竖屏（portrait） |

## 2. 核心概念

### 2.1 试管（Tube）

- 每根试管可容纳 **4 格**液体（自底向上编号 1~4）
- 液体按层堆叠，不同颜色互不相溶，各自占据独立格子
- 试管状态：满（4/4）、部分填充、空（0/4）

```
示意图（一根试管）:

  ┌──┐
  │  │  ← 第4格（顶部）
  │██│  ← 第3格 红色
  │██│  ← 第2格 蓝色
  │██│  ← 第1格 红色（底部）
  └──┘
```

### 2.2 液体（Liquid）

- 每种颜色的液体总量恰好为 **4 格**（刚好填满一根试管）
- 颜色种类数 = 需要排序的试管数
- 液体之间不混合，倒入后按层叠放

## 3. 关卡设计

### 3.1 关卡参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 颜色数 | C | 需要排序的颜色种类 |
| 满管数 | C | 等于颜色数，每根初始装有4格随机颜色液体 |
| 空管数 | E | 额外的空试管，用于周转 |
| 试管总数 | T = C + E | 屏幕上的试管总数 |

### 3.2 难度阶梯

| 难度 | 颜色数(C) | 空管数(E) | 试管总数(T) | 说明 |
|------|-----------|-----------|-------------|------|
| 入门 | 3 | 2 | 5 | 新手引导 |
| 简单 | 5 | 2 | 7 | 基础关卡 |
| 中等 | 8 | 2 | 10 | 需要策略 |
| 困难 | 10 | 2 | 12 | 需要规划 |
| 挑战 | 12 | 2 | 14 | 高阶挑战 |

### 3.3 关卡生成算法

采用「逆向打乱」法确保 100% 可解：

```
1. 构造目标状态：C 根试管各装满同一颜色，E 根空管
2. 执行 K 次随机合法的「逆向倒水」操作打乱
3. K 值随难度递增（入门 20 次，困难 80+ 次）
4. 验证初始状态并非已完成状态
```

## 4. 操作规则

### 4.1 倒水操作

玩家点击两根试管完成一次倒水：

1. **第一次点击** — 选中「源试管」（高亮提示，试管上升动画）
2. **第二次点击** — 选中「目标试管」，尝试倒水

### 4.2 倒水合法性判定

必须同时满足以下条件才能执行倒水：

| 条件 | 说明 |
|------|------|
| 源管非空 | 源试管至少有 1 格液体 |
| 目标管未满 | 目标试管至少有 1 格空位 |
| 颜色匹配 **或** 目标管为空 | 源管顶部颜色 == 目标管顶部颜色，或目标管是空的 |
| 不是自己倒自己 | 源管 ≠ 目标管 |

### 4.3 倒水量计算

一次倒水操作会倒出**源管顶部所有连续同色的液体**，但不超过目标管的剩余空间：

```
源管状态: [红, 蓝, 蓝, 蓝]  （顶部3格蓝色）
目标管:   [蓝, _, _, _]     （3格空位，顶部蓝色）

→ 倒出量 = min(连续同色数 3, 目标空位数 3) = 3

结果:
源管: [红, _, _, _]
目标: [蓝, 蓝, 蓝, 蓝]  ✅ 完成一色！
```

### 4.4 取消选择

- 点击已选中的源管 → 取消选择
- 点击空白区域 → 取消选择
- 倒水失败（不合法）→ 自动取消选择，给出反馈

## 5. 胜利与失败

### 5.1 胜利条件

所有非空试管都只包含**同一种颜色**且装满（4/4）。

```
胜利示例（5管3色2空）:
  [红红红红] [蓝蓝蓝蓝] [绿绿绿绿] [空] [空]  ✅
```

### 5.2 无失败状态

- 本游戏**没有失败判定**，玩家可以无限尝试
- 提供「撤销」功能帮助玩家回退错误操作

## 6. 辅助功能

### 6.1 撤销（Undo）

- 点击撤销按钮，回退上一步操作
- 支持多步撤销（记录完整操作历史）
- 无次数限制

### 6.2 重开（Restart）

- 将当前关卡恢复到初始状态
- 清空操作历史

### 7.1 试管排列

| 试管总数 | 排列方式 |
|----------|----------|
| ≤ 7 | 单行排列 |
| 8 ~ 14 | 双行排列（上行较多或相等） |

### 7.2 交互反馈

| 交互 | 反馈 |
|------|------|
| 选中试管 | 试管向上偏移 8px，边框高亮 |
| 倒水成功 | 液体流动动画（简易：颜色块移动） |
| 倒水失败 | 试管短暂抖动，取消选中 |
| 关卡通关 | 全屏撒花 / 弹出结算面板 |

## 8. 颜色方案

基础调色板（8 色，可扩展）：

| 编号 | 名称 | RGB | 用途 |
|------|------|-----|------|
| 1 | 红色 | (220, 60, 60) | 高辨识度 |
| 2 | 蓝色 | (60, 120, 220) | 高辨识度 |
| 3 | 绿色 | (60, 180, 80) | 高辨识度 |
| 4 | 黄色 | (240, 200, 40) | 暖色系 |
| 5 | 紫色 | (160, 80, 200) | 冷色系 |
| 6 | 橙色 | (240, 140, 40) | 暖色系 |
| 7 | 青色 | (40, 200, 200) | 冷色系 |
| 8 | 粉色 | (240, 120, 160) | 辅助色 |

选色原则：相邻颜色色相差 ≥ 40°，确保色弱玩家可辨识。

## 9. 数据结构

### 9.1 关卡状态

```lua
-- 一根试管 = 一个数组，索引1为底部，索引N为顶部
-- 0 或缺失 = 空格，数字 = 颜色编号
local gameState = {
    tubes = {
        { 1, 3, 2, 1 },   -- 试管1: 底红-绿-蓝-红
        { 2, 1, 3, 2 },   -- 试管2: 底蓝-红-绿-蓝
        { 3, 2, 1, 3 },   -- 试管3: 底绿-蓝-红-绿
        {},                -- 试管4: 空
        {},                -- 试管5: 空
    },
    capacity = 4,          -- 试管容量
    moveCount = 0,         -- 步数
    history = {},          -- 操作历史（用于撤销）
}
```

### 9.2 操作记录

```lua
-- 一次操作
local move = {
    from = 1,          -- 源试管索引
    to = 4,            -- 目标试管索引
    count = 2,         -- 倒出的液体格数
    colors = { 1, 1 }, -- 倒出的颜色序列（用于撤销还原）
}
```
