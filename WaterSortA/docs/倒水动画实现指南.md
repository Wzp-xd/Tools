# 倒水动画实现指南

> 本文档总结了「水排序」游戏中倒水动画的核心实现思路与关键算法，可作为在其他项目中实现类似"容器倾斜倒液体"功能的参考。

---

## 1. 整体架构

### 1.1 模块化设计

项目采用模块化架构，各职责分离：

```
scripts/
├── config.lua          # 全局配置表（所有可调参数集中管理）
├── GameState.lua       # 游戏数据层（试管数据、选中、撤销、通关检测）
├── Animation.lua       # 动画状态机（倾倒、抖动、选中偏移、胜利粒子）
├── Renderer.lua        # NanoVG 渲染层（静态管、倾斜水面、水流、特效）
├── LevelGenerator.lua  # 关卡生成（洗牌 + 质量评估）
└── main.lua            # 入口文件（组装模块、UI 构建、帧循环）
```

**核心设计原则**：
- **Config 驱动** — 所有数值参数集中在 `config.lua`，修改配置即可调整效果
- **数据与动画分离** — `GameState` 负责纯数据逻辑，`Animation` 负责表现层
- **延迟数据提交** — 动画期间不修改目标管数据，动画结束后才正式提交

### 1.2 四阶段动画状态机

倒水动画由一个四阶段状态机驱动（`Animation.lua`）：

```
none → move → tilt → pour → return → none
```

| 阶段 | 描述 | 持续时间 | 配置字段 |
|------|------|----------|---------|
| **move** | 源管移动到目标管口上方 | 0.30s | `Config.animation.moveDuration` |
| **tilt** | 源管从 0° 倾斜到 `angleStart` | 0.20s | `Config.animation.tiltDuration` |
| **pour** | 角度实时计算（物理正确），液体持续倒出 | 每层 0.28s | `Config.animation.pourPerLayer` |
| **return** | 源管回正并归位 | 0.30s | `Config.animation.returnDuration` |

```lua
-- 状态转换逻辑（Animation:update() 每帧执行）
if phase == "move" and timer >= moveDuration then
    phase = "tilt"; timer = 0
elseif phase == "tilt" and timer >= tiltDuration then
    phase = "pour"; timer = 0; pouredSoFar = 0
elseif phase == "pour" and timer >= pourLayers * pourPerLayer then
    phase = "return"; timer = 0; pouredSoFar = pourLayers
elseif phase == "return" and timer >= returnDuration then
    phase = "none"; pourFinished = true  -- 通知主模块提交数据
end
```

### 1.3 延迟数据提交模式 🔴

**这是本项目最关键的设计决策**，解决了"倒水时目标管立刻满"的 bug：

```
点击倒水 → 仅从源管 table.remove() → 启动动画
     ↓
动画播放中（0.8~1.5s）→ 目标管数据不变
     ↓
Animation:update() 返回 pourFinished=true
     ↓
HandleUpdate 中执行 table.insert(dst, pourColor) → 正式提交
```

**为什么需要延迟**：
- 如果立刻向目标管添加数据，渲染时目标管液面会"瞬间满"
- 动画的 `pour.pouredSoFar` 控制目标管的**视觉水面高度**（extraFill），与实际数据分离
- 动画结束后才让数据层与视觉层同步

### 1.4 核心设计原则

1. **水面始终水平于地面** — 管子倾斜时（<90°），水面仍保持水平
2. **物理正确的倾斜角度** — 角度由 `atan(deficit / halfInnerW)` 实时计算
3. **体积守恒** — 倾斜不改变液体体积，只改变液面形态
4. **相位连续性** — 各阶段过渡无跳变
5. **超水平倾倒** — 倒空时角度超过 90°，以管壁为底渲染残留液体

## 2. 关键几何参数

所有参数集中定义在 `config.lua`：

```lua
Config.tube = {
    width       = 56,     -- 管外宽 (px)
    height      = 190,    -- 管外高 (px)
    wall        = 6,      -- 壁厚 (px)
    gap         = 24,     -- 试管间距 (px)
    rowGap      = 50,     -- 双行间距 (px)
    layerCount  = 4,      -- 每管层数
    bottomR     = 6,      -- 底部圆角半径 (px, 仅外壳装饰)
}

-- 派生参数（平底矩形截面）
local innerH     = height - 2 * wall                   -- 管内净高度 = 178
local halfInnerW = (width - 2 * wall) / 2              -- 管内半宽 = 22
local layerH     = innerH / layerCount                 -- 每层高度 = 44.5
```

管内截面示意（平底 + 外壳小圆角）：

```
       ← TUBE_WIDTH (56) →
       |    ← 2*halfInnerW (44) →    |
       |_____|___________________|_____|   ← 管口 (tubeTop)
       |     |                   |     |
  壁厚→|     |   液体区域(矩形)  |     |← 壁厚(6)
  (6)  |     |                   |     |
       |     |___________________|     |   ← innerBottom (floorY)
       |_____╲___________________╱_____|   ← 外壁小圆角(R=6, outerR=12)
```

**关键设计**：
- 管内为纯矩形空间（平底），无内壁圆角
- 外壳底部仅有小圆角装饰（`outerR = bottomR + wall = 12`）
- 水层统一用矩形填充，无需处理底部弧线
- 倾斜时管内轮廓也是简单矩形旋转（4个顶点），无圆弧采样

## 3. 物理倾斜角度计算

### 3.1 核心公式

当管子倾斜时，液面要到达管口（才能倒出液体）所需的最小倾斜角由以下几何关系决定：

```
α = atan(deficit / halfInnerW)
```

其中：
- `deficit = innerH - waterH`：液面距管口的垂直距离
- `waterH = remaining * layerH`：当前液面高度（从管底算起）
- `halfInnerW`：管内半宽（22px）

### 3.2 公式极限问题与解决方案

**问题**：对于纵横比较大的管子（innerH/halfInnerW = 178/22 ≈ 8:1），`atan` 的极限值约为 83°，永远无法达到 90°。要完全倒空瓶子，需要超过水平（≥90°）。

**解决方案**：当剩余不足 1 层时，从物理角度平滑过渡到 `tiltAngleMax`（100°）：

```lua
-- Animation.lua 中的实现
function Animation.getTiltAngleForRemaining(remaining)
    local tube = Config.tube
    local anim = Config.animation
    local innerH = tube.height - 2 * tube.wall
    local halfInnerW = (tube.width - 2 * tube.wall) / 2
    local layerH = innerH / tube.layerCount
    local waterH = remaining * layerH

    if waterH < 0.5 then
        return anim.tiltAngleMax  -- 几乎空管，直接最大角度
    end
    local deficit = innerH - waterH
    if deficit <= 0 then
        return anim.tiltAngleMin  -- 满管，最小角度即可
    end
    local angle = math.atan(deficit / halfInnerW)
    -- 不足1层时,从物理角度平滑过渡到最大角度
    if remaining < 1 then
        local t = 1 - remaining
        angle = angle + (anim.tiltAngleMax - angle) * t
    end
    return clamp(angle, anim.tiltAngleMin, anim.tiltAngleMax)
end
```

### 3.3 角度示例

| 剩余层数 | 物理角度 | 实际角度（含过渡） |
|---------|---------|-----------------|
| 4 (满管) | 18° (最小值) | 18° |
| 3 | ≈61° | 61° |
| 2 | ≈75° | 75° |
| 1 | ≈80.6° | 80.6°（过渡起点） |
| 0.5 | ≈81.9° | ≈91°（超过水平） |
| 0.1 | ≈83° | ≈98° |
| ≈0 | - | 100°（最大值） |

### 3.4 Pour 阶段：实时物理角度（非线性插值）

**关键设计**：倒水过程中角度由剩余液量实时计算，而非线性插值。

```lua
-- main.lua drawAnimSource() 中 pour 阶段的角度计算
elseif pour.phase == "pour" then
    curCX = targetCX
    curCY = targetCY
    local effectiveRemaining = srcTotal - pour.pouredSoFar
    curAngle = Animation.getTiltAngleForRemaining(effectiveRemaining) * tiltDir
```

**为什么不能用 lerp**：
- `lerp(angleStart, angleEnd, t)` 在中间点给出的角度 < 物理正确角度
- 例：满管→半管，lerp 中点 = 40°，但物理需要 61°
- 结果：水面会低于管口，视觉上倒水时液面"陷下去"

## 4. 双模式渲染：<90° 水平液面 vs ≥90° 贴壁矩形

### 4.1 设计思路

`math.tan(angle)` 在 90° 时趋于无穷大，>90° 时变为负值，导致水面计算崩溃。因此需要两种渲染模式：

| 角度范围 | 渲染模式 | 物理含义 |
|---------|---------|---------|
| < 90° | 水平液面裁剪 | 液面保持水平，用 tan 计算倾倒侧高度 |
| ≥ 90° | 贴壁矩形 | 管子过水平，残余液体贴着倾倒侧管壁 |

### 4.2 ≥90° 贴壁矩形渲染

当角度超过 90° 时，管口朝下，液体应贴在倾倒侧管壁上：

```lua
-- Renderer.lua drawTiltedWater() 中的实现
if absAngle >= math.pi * 0.5 then
    -- 体积守恒: 面积不变，厚度 = 面积 / 管高
    local thickness = effectiveRemaining * layerH * (2 * halfInnerW) / innerH
    if thickness < 0.5 then return end  -- 太薄不渲染

    -- 在管局部坐标中构建贴壁矩形
    local rectX1, rectX2
    if angle >= 0 then
        -- 倾倒侧是右壁
        rectX1 = innerRight - thickness
        rectX2 = innerRight
    else
        -- 倾倒侧是左壁
        rectX1 = innerLeft
        rectX2 = innerLeft + thickness
    end
    -- 旋转四角到世界坐标，单色填充
    ...
    return  -- 不执行后续 tan-based 逻辑
end
```

### 4.3 过渡连续性

在 90° 临界点两种模式自然衔接：
- **89.9°**（tan 模式）：`tan(89.9°)` 极大，`hPour` 被 `min` 钳到 `innerH`，液体铺满管内宽度变成极薄的一层
- **90°**（贴壁模式）：`thickness` 也很小（remaining < 1 时液体本就极少），同样是薄层

两者视觉效果一致，无跳变。

### 4.4 为什么 ≥90° 不能用 tan

```
tan(89°)  = +57.29   ← 正常（被 min 钳住）
tan(90°)  = +∞       ← Lua 返回极大数（被 min 钳住，勉强可用）
tan(91°)  = -57.29   ← 负数！hPour 变为负值，渲染崩溃
tan(100°) = -5.67    ← 同上
```

## 5. 体积守恒的水面计算（<90° 模式）

### 5.1 核心思路

倾斜时液体体积不变，但液面在管的不同侧高度不同。关键洞察：

> 在管局部坐标系中，液体平均高度 = `remaining * layerH`。
> 倾斜 α 角后，倾倒侧液面比对侧高出 `2 * halfInnerW * tan(α)`。
> 取倾倒侧的液面高度，旋转到世界坐标，即为水面 Y。

### 5.2 计算步骤

```lua
-- Renderer.lua drawTiltedWater() 中的实现
-- 步骤1: 计算倾倒侧液面高度（管局部坐标，从管底往上）
local avgH = effectiveRemaining * layerH
local tanA = math.tan(math.abs(angle))
local hPour = avgH + halfInnerW * tanA  -- 倾倒侧高于平均值
hPour = math.min(hPour, innerH)          -- 不超过管高

-- 步骤2: 确定倾倒侧墙面X坐标（管局部坐标）
local pourWallX = (angle >= 0) and (cx + halfInnerW) or (cx - halfInnerW)

-- 步骤3: 计算该点的局部Y坐标
local innerBottom = cy + halfH - wall  -- 管内底面
local pourWallWaterLocalY = innerBottom - hPour

-- 步骤4: 旋转到世界坐标，得到水面Y
local _, waterY = rotatePoint(pourWallX, pourWallWaterLocalY, pivotX, pivotY, angle)

-- 步骤5: angle=0时回退到静态位置（保证连续性）
if math.abs(angle) < 0.001 then
    waterY = innerBottom - effectiveRemaining * layerH
end
```

## 6. 旋转中心（Pivot Point）

### 6.1 选择依据

旋转中心选在**管口靠近目标管**的角点：

```lua
-- main.lua drawAnimSource() 中的实现
-- 源管在目标管左侧 → 绕管口右角旋转 (tiltDir = +1)
-- 源管在目标管右侧 → 绕管口左角旋转 (tiltDir = -1)
local isLeft = srcPos.x <= dstPos.x
local pivotLocalX = isLeft and halfW or -halfW
local pivotLocalY = -halfH  -- 管顶
```

### 6.2 坐标变换

通用旋转函数（`Renderer.lua` 导出）：

```lua
function Renderer.rotatePoint(px, py, ox, oy, angle)
    local dx, dy = px - ox, py - oy
    local c, s = math.cos(angle), math.sin(angle)
    return ox + dx*c - dy*s, oy + dx*s + dy*c
end
```

## 7. 多层颜色渲染（Sutherland-Hodgman 裁剪）

### 7.1 问题

管子倾斜后（<90°），各色层的边界不再是简单的水平矩形，而是与管壁轮廓的交集区域。

### 7.2 管内轮廓构建

倾斜时管内轮廓是一个旋转后的简单矩形（4个顶点）：

```lua
-- Renderer.lua 中的实现
-- 管内四角（纯矩形，无圆弧）
local ltx, lty = rotatePoint(innerLeft, innerTop, pivotWX, pivotWY, angle)   -- 左上
local lbx, lby = rotatePoint(innerLeft, innerBottom, pivotWX, pivotWY, angle) -- 左下
local rbx, rby = rotatePoint(innerRight, innerBottom, pivotWX, pivotWY, angle) -- 右下
local rtx, rty = rotatePoint(innerRight, innerTop, pivotWX, pivotWY, angle)   -- 右上

-- 顺时针轮廓
outline = { {ltx,lty}, {lbx,lby}, {rbx,rby}, {rtx,rty} }
```

### 7.3 算法流程

```
1. 构建旋转后的管内矩形轮廓 (outline, 4顶点)
2. 用 waterY 水平线裁剪，得到水面以下区域 (clippedPoly)
3. 对每个颜色层：
   a. 计算该层的顶部Y和底部Y (物理公式)
   b. 用 Sutherland-Hodgman 将 clippedPoly 裁剪到 [topY, bottomY] 水平带
   c. 用该层颜色填充裁剪后的多边形
```

### 7.4 Sutherland-Hodgman 实现

```lua
-- Renderer.lua 中的裁剪函数
-- 裁剪到 y >= clipY (保留下方)
local function clipPolyAbove(poly, clipY) ... end

-- 裁剪到 y <= clipY (保留上方)
local function clipPolyBelow(poly, clipY) ... end
```

### 7.5 线段与水平线求交

```lua
local function segHIntersect(x1, y1, x2, y2, hY)
    if (y1 - hY) * (y2 - hY) > 0 then return nil end  -- 同侧
    if math.abs(y2 - y1) < 0.001 then return nil end   -- 近水平
    local t = (hY - y1) / (y2 - y1)
    return x1 + t * (x2 - x1)
end
```

## 8. 层边界的物理计算

每一层的"顶部"，等价于"假设管内只有 j 层液体时的水面高度"：

```lua
for j = 0, layerCount do
    if j == 0 then
        layerYPositions[0] = maxY  -- 管底最低点
    else
        local hJ = j * layerH + halfInnerW * tanA
        hJ = math.min(hJ, innerH)
        local localY_j = innerBottom - hJ

        if absAngle < 0.001 then
            layerYPositions[j] = localY_j
        else
            local _, worldY_j = rotatePoint(pourWallX, localY_j, pivotX, pivotY, angle)
            layerYPositions[j] = worldY_j
        end
    end
end
```

### 9.2 弧形水流（二次曲线模拟重力）

```lua
-- Renderer.lua drawWaterStream() 中的实现
for s = 0, segments do
    local t = s / segments
    local px = lerp(startX, endX, t)       -- X: 线性
```

### 10.1 NanoVG Arc 方向规则

### 10.2 外壳构建（填充 + 描边）

```lua
-- Renderer.lua drawGlassShell() 中的实现
-- 外壁: U 形 + 底部小圆角
nvgMoveTo(nvg, tubeLeft, tubeTop)
nvgLineTo(nvg, tubeLeft, tubeBottom - outerR)
nvgArc(nvg, tubeLeft + outerR, tubeBottom - outerR, outerR, math.pi, math.pi * 0.5, 1)

-- 内壁（简单矩形，反向路径用于镂空）

nvgLineTo(nvg, innerLeft, tubeTop)
nvgClosePath(nvg)
```

### 10.3 设计选择

- **外壁**：带圆角弧线的 U 形路径（`outerR = bottomR + wall = 12`）
- **内壁**：简单矩形（不带圆角），避免弧线方向与路径绕行冲突
- **水层**：所有层统一用 `nvgRect` 矩形填充，管内空间为纯矩形

## 11. 倒空处理

### 11.1 问题

当管子全部倒空（remaining→0）时存在两个问题：
1. `atan(deficit/halfInnerW)` 极限约 83°，永远无法达到 90°
2. 极少量液体仍然被渲染，在切换到 return 阶段时突然消失

### 11.2 解决方案（三重保障）

```lua
-- 1. getTiltAngleForRemaining: 不足1层时平滑过渡到100°
if remaining < 1 then
    local t = 1 - remaining
    angle = angle + (tiltAngleMax - angle) * t
end

-- 2. getTiltAngleForRemaining: 极小量直接最大角度
if waterH < 0.5 then
    return tiltAngleMax
end

-- 3. drawTiltedWater: 近似空管不渲染
if remaining <= 0.05 then return end
```

### 11.3 ≥90° 时的贴壁矩形渲染

当角度达到或超过 90° 时，切换到贴壁矩形模式（见第 4 章），避免 `tan()` 奇异点，同时视觉上表现为液体贴着管壁流出的最后残留。

## 12. 常见陷阱与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 目标管水面立刻满 | 倒水时立即修改目标管数据 | **延迟数据提交**：动画结束后才 `table.insert(dst)` |
| 水面随管旋转 | 在 NanoVG 变换矩阵内绘制液体 | 液体独立绘制，手动旋转顶点 |
| 倒水时水面低于管口 | pour 阶段用 `lerp` 线性插值角度 | 改用 `getTiltAngleForRemaining` 实时计算 |
| 底部圆角向内凹 | `nvgArc` 的 dir 参数错误 | UrhoX 中用 `dir=1` 表示短弧 |
| 水层底部凹陷 | 水层用弧线绘制或轮廓含弧线 | 水层和管内轮廓统一用矩形 |
| 倒空时角度不够 | `atan` 极限 ≈83°，达不到 90° | remaining<1 时平滑过渡到 100° |
| 角度>90°渲染崩溃 | `tan(>90°)` 为负值 | ≥90° 切换到贴壁矩形模式 |
| 倒空时液体突然消失 | remaining→0 突然切换阶段 | waterH<0.5 阈值 + remaining<=0.05 不渲染 |
| 水流与目标液面断层 | 水流终点在管口而非液面 | 终点改为 `floorY - fillTotal * layerH` |
| 多色层出现交叉 | 裁剪算法未维持多边形绕序 | 使用 Sutherland-Hodgman 逐边裁剪 |
| angle=0 和 angle≈0 不连续 | tan(0)=0 但旋转可能有误差 | 增加 `absAngle < 0.001` 的回退分支 |
| 倾斜时管底残留液体 | 管内轮廓含圆弧采样点 | 管内轮廓改为纯矩形（4顶点） |
