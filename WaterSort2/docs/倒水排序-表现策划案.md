# 倒水排序 — 表现策划案

---

## 一、游戏概述

| 项目 | 说明 |
|------|------|
| 类型 | 休闲益智 |
| 视角 | 2D 正面视角 |
| 核心玩法 | 将不同颜色的水在试管间来回倒，使每个试管只含一种颜色 |
| 目标用户 | 全年龄段休闲玩家 |
| 技术栈 | UrhoX 引擎 + NanoVG 矢量渲染 + Lua 脚本 |

---

## 二、核心玩法规则

1. 场景内有若干试管（5~14 根），每根试管可容纳 **4 层**水
2. 水只能倒入**顶层颜色相同**或**空的**试管
3. 每次操作将源试管顶部**连续相同颜色**的所有层一次性倒出
4. 目标管剩余容量必须 >= 倒出层数，否则不可操作
5. 所有试管各自只含单一颜色（或为空）时，关卡通过

## 四、交互设计

### 4.1 操作流程

```
点击试管A（选中） → 点击试管B（倒水） → 动画播放 → 判定是否通关
```

### 4.2 状态表现

| 状态 | 表现 | 配置字段 |
|------|------|---------|
| 默认 | 试管静止 | — |
| 选中 | 试管**上移 22px** + 底部蓝色椭圆光圈 | `Config.interaction.selectOffset` |
| 选中动画 | 指数衰减插值，速度因子=12 | `Config.interaction.selectAnimSpd` |
| 不可倒入 | 阻尼正弦波**抖动** 0.3s，振幅5px，频率7 | `Config.interaction.shake*` |
| 倒水中 | 源试管倾斜，水流弧线流入目标管 | 见 §4.3 |
| 通关 | 试管波浪弹跳 + 彩色粒子喷射 + "恭喜过关"文字 | `Config.winEffect` |

### 4.3 倒水动画详细分解

总时长约 0.8~1.6s，取决于倒出层数（总时长 = 0.30 + 0.20 + N×0.28 + 0.30）。

#### 阶段一：移动就位（0.30s）

源试管从原始位置**平移**到目标试管管口上方：
- 旋转支点（管口角）对齐到目标管口边缘旁（间距 5px）
- 管口高于目标管口 30px
- 如果源试管在目标左侧，则移到目标左上方；反之右上方
- 缓动函数：EaseInOutQuad

```
示意图（源在左侧时）：

    移动前                移动后
                            ┃S┃
    ┃S┃      ┃T┃         ↗  ┃T┃
    ┃██┃     ┃██┃       ┃██┃ ┃██┃
    ┃██┃     ┃██┃       ┃██┃ ┃██┃
    ┗━━┛     ┗━━┛       ┗━━┛ ┗━━┛
```

#### 阶段二：倾斜到出水角（0.20s）

源试管绕**靠近目标管一侧的管口角点**旋转倾斜：
- 倾斜角度：由物理公式 `atan(deficit/halfInnerW)` 计算（满管 ≈18°，非固定值）
- 旋转中心：管口靠近目标管的那个角点
- 倾斜过程中水面保持水平（水面相对地面始终平行）
- 缓动函数：EaseOutQuad

```
示意图：
         ╲S╲
          ╲██╲   ← 物理正确角度（约18°~80°视液面高度）
           ╲━━╲
              ┃T┃
              ┃██┃
              ┃██┃
              ┗━━┛
```

#### 阶段三：倒水流出（每层 0.28s）

核心动画阶段，角度随液面**实时物理计算**（非固定角度）：

**① 源试管角度动态变化**
- 角度由 `getTiltAngleForRemaining(remaining)` 实时计算
- 液体越少角度越大（18° → 80° → 100°），精确匹配"水面刚好在管口"的物理状态
- 最后不足1层时，角度平滑过渡到 100°（超过水平确保倒空）

**② 源试管水面下降**
- 倾斜状态下水面保持水平，通过 Sutherland-Hodgman 多边形裁剪渲染多色层
- 当角度 ≥90° 时切换为"贴壁矩形"模式（体积守恒）

**③ 水流连线**
- 起点：源管口角旋转后的世界坐标
- 终点：目标管当前液面高度（非管口！含已倒入量）
- 宽度：7px（`Config.render.streamWidth`）
- 路径：X 线性 + Y 二次加速（模拟重力抛物线）
- 宽度沿路径用 sin 渐变（中间粗两头细）

**④ 目标试管水面上升（视觉）**
- 通过 `extraFill = pour.pouredSoFar` 控制视觉液面
- 实际数据在动画结束后才添加（延迟数据提交）

```
示意图（倒水过程中）：

         ╲S╲
          ╲█ ╲   ← 水面在下降，角度在增大
           ╲━━╲
            ┆     ← 水流柱（7px宽，二次曲线）
            ↓
           ┃T┃
           ┃██┃   ← 视觉水面在上升
           ┃██┃
           ┃██┃
           ┗━━┛
```

#### 阶段四：回正归位（0.30s）

- 角度与位置同时插值回初始状态
- 缓动函数：EaseInOutQuad
- 水流在进入此阶段前已消失

#### 动画参数汇总

| 参数 | 值 | 配置字段 |
|------|-----|---------|
| 移动就位时长 | 0.30s | `Config.animation.moveDuration` |
| 倾斜时长 | 0.20s | `Config.animation.tiltDuration` |
| 每层倒水时长 | 0.28s | `Config.animation.pourPerLayer` |
| 回正归位时长 | 0.30s | `Config.animation.returnDuration` |
| 最小倾斜角（满管） | 18° | `Config.animation.tiltAngleMin` |
| 最大倾斜角（倒空） | 100° | `Config.animation.tiltAngleMax` |
| 水流宽度 | 7px | `Config.render.streamWidth` |
| 水流段数 | 10段 | `Config.render.streamSegments` |
| 旋转中心 | 管口靠近目标侧的角点 | — |
| 管口水平间距 | 5px | `Config.render.pourTipOffset` |
| 管口垂直间距 | 30px | `Config.render.pourAboveOffset` |
| 移动缓动 | EaseInOutQuad | `Animation.Easing.inOutQuad` |
| 倾斜缓动 | EaseOutQuad | `Animation.Easing.outQuad` |
| Pour 阶段角度 | 实时物理计算（非插值） | `Animation.getTiltAngleForRemaining` |

#### 边界情况处理

| 情况 | 处理 |
|------|------|
| 目标管只剩1格容量但源有2层同色 | 只倒1层，按实际层数计算 |
| 动画过程中玩家点击 | 忽略输入（`game.isAnimating` 锁定） |
| 源与目标相邻 | 移动距离缩短，但仍保持完整动画流程 |
| 源与目标距离很远 | 移动速度不变（0.3s），视觉上移动更快 |
| 管子倒空（角度超90°） | 切换贴壁矩形渲染，避免 tan() 奇异点 |

## 六、关卡设计

### 6.1 预设关卡（13关）

| 关卡段 | 关卡号 | 管数 | 颜色数 | 空管数 | 难度说明 |
|--------|--------|------|--------|--------|----------|
| 入门 | 1~3 | 5 | 3 | 2 | 入门引导，容错高 |
| 进阶 | 4~6 | 6 | 4 | 2 | 基础关卡 |
| 中级 | 7~8 | 7 | 5 | 2 | 中等难度 |
| 高级 | 9~10 | 8 | 6 | 2 | 需要规划 |
| 困难 | 11~12 | 9 | 7 | 2 | 需要深思 |
| 大师 | 13 | 10 | 8 | 2 | 高难挑战 |

### 6.2 无限关卡生成

超出13关后，使用公式动态生成配置：

| 参数 | 规则 | 配置字段 |
|------|------|---------|
| 颜色增长 | 每3关增加1色 | `Config.infiniteLevelRule.colorIncreaseInterval` |
| 颜色上限 | 最多10色 | `Config.infiniteLevelRule.maxColors` |
| 管数上限 | 最多14管 | `Config.infiniteLevelRule.maxTubes` |
| 空管数 | 通常2个，偶尔3个（高难度且关卡号%5==0时） | `emptyMin/emptyMax` |

公式：`colors = min(8 + floor((level-13)/3), 10)`, `tubes = min(colors + 2, 14)`

### 6.3 关卡生成质量控制

使用 `LevelGenerator.lua` 的 `generateQuality()` 方法：
- Fisher-Yates 洗牌生成初始布局
- 评估"混乱度"（相邻不同色的数量），淘汰混乱度过低的布局（太容易解开）
- 最多尝试 N 次，取混乱度最高的布局

## 九、技术架构

### 9.1 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 配置中心 | `config.lua` | 所有可调参数集中管理（几何、动画、颜色、关卡） |
| 游戏逻辑 | `GameState.lua` | 试管数据、倒水判定、撤销栈、通关检测 |
| 动画系统 | `Animation.lua` | 4阶段状态机、缓动函数、物理角度计算、粒子模拟 |
| 渲染引擎 | `Renderer.lua` | NanoVG 绘制（试管、倾斜水面、水流、粒子） |
| 关卡生成 | `LevelGenerator.lua` | Fisher-Yates 洗牌 + 质量评估 |
| 入口组装 | `main.lua` | Widget UI 构建、输入处理、帧循环、延迟数据提交 |

### 9.2 核心设计模式

| 模式 | 说明 |
|------|------|
| Config 驱动 | 修改 `config.lua` 即可调节所有数值，无需改业务代码 |
| 数据/表现分离 | GameState 纯数据，Animation 纯表现，互不依赖 |
| 延迟数据提交 | 倒水动画期间不修改目标管，结束后才正式 `table.insert` |
| 快照机制 | 动画前保存源管快照，渲染时基于快照计算倾斜水面 |
| 自定义 Widget | 继承 Widget:Extend 实现游戏画布，集成到 UI 树 |

### 9.3 渲染技术

| 技术 | 用途 |
|------|------|
| NanoVG 矢量绘制 | 管壁、水层、水流、粒子、文字 |
| Sutherland-Hodgman 裁剪 | 倾斜时多色层精确裁剪 |
| 物理角度计算 | `atan(deficit/halfInnerW)` 确保水面恰好在管口 |
| 双模式渲染 | <90° 水平液面 / ≥90° 贴壁矩形 |
| 旋转变换 | 支点旋转绘制倾斜管壳 |
| 二次曲线 | 水流 Y 轴加速模拟重力 |

### 9.4 关键依赖

| 依赖 | 用途 |
|------|------|
| `urhox-libs/UI` | 构建顶栏、按钮等 UI 控件 |
| `urhox-libs/UI/Core/Widget` | 自定义游戏画布的基类 |
| NanoVG（引擎内置） | 所有矢量图形绘制 |
