# 试管排序 — 视觉设计方案

> 基于参考图 `assets/image/reference-tube-style.png` 的分析与重绘方案

---

## 1. 参考图视觉特征分析

### 1.1 整体比例

| 特征 | 参考图观察 | 当前值 | 建议值 |
|------|-----------|--------|--------|
| 管宽/管高比 | 约 1:7~1:8，非常修长 | 60px 宽，总高 ~220px (1:3.7) | **50px 宽**，增加 slotHeight 至 **55px**，总高 ~310px (1:6.2) |
| 管壁厚度 | 很薄，约占管宽 5% | 4px (6.7%) | **3px** (6%) |
| 球底高度 | 半球底，约占管宽 50% | 25px (42%) | **28px** (56%)，更饱满的半球 |
| 管口椭圆度 | 较窄的椭圆开口 | 0.35 | **0.30**，略微收窄 |
| 管间距 | 紧凑，约管宽 25% | 20px (33%) | **14px** (28%) |
| 管口空白 | 管口到第一格液面距离较大 | 10px | **15px**，与参考图匹配的通透感 |

**关键变化**：管身大幅拉长（slotHeight 40→55），管宽略窄（60→50），整体比例更修长。

### 1.2 玻璃管壁

参考图的玻璃质感非常突出，分析关键渲染层：

| 层次 | 参考图特征 | 当前实现 | 差异 |
|------|-----------|---------|------|
| **主高光带** | 左侧 15%~25% 位置，白色，非常亮，几乎贯穿全管 | alpha=28，位置 8%~28% | alpha **偏低**，需增至 **50~60** |
| **次高光带** | 右侧 75%~85%，较弱但可见 | alpha=10 | alpha 提至 **18~22** |
| **左边缘暗线** | 极左 0%~3%，明显暗线 | alpha=12，位置 0%~5% | alpha 提至 **25~30** |
| **右边缘暗线** | 极右 97%~100%，较弱暗线 | 当前 alpha * 0.75 | 基本一致 |
| **管壁底色** | 淡蓝色半透明色调 | 无底色（纯渐变叠加） | **需新增**：蓝色调管壁底色 |
| **球底高光** | 偏左上方，较明显的白色光斑 | alpha=22，size=0.3 | alpha 提至 **35~40** |
| **管口厚度环** | 明显可见的管口截面，有厚度感 | alpha=30 | 提至 **45~50** |

**关键差异**：参考图的玻璃高光强度远高于当前实现，且管壁有蓝色调底色。

### 1.3 液体渲染

| 特征 | 参考图观察 | 当前实现 | 差异 |
|------|-----------|---------|------|
| **不透明度** | 几乎完全不透明 | alpha=210 (82%) | 提至 **240** (94%) |
| **边缘暗化** | 两侧明显暗化，约占宽度 18%~22% | alpha=40, width=20% | alpha 提至 **55~60** |
| **左侧高光条** | 与玻璃主高光对齐，明亮竖条 | alpha=25, width=8%, pos=22% | alpha 提至 **40~45** |
| **液面椭圆** | 顶部明亮椭圆，颜色比主体亮 30% | 有实现 | 基本一致 |
| **格间过渡** | 格与格之间无明显缝隙，颜色直接衔接 | 桶形闭合路径 | 当前实现已无缝 |
| **液柱 3D 感** | 像圆柱体，强烈的明暗变化 | 有边缘暗化+高光 | 需**增强对比度** |

### 1.4 背景

| 特征 | 参考图 | 当前实现 |
|------|--------|---------|
| 顶部色 | 深海军蓝 ~(12, 15, 35) | (15, 15, 30) |
| 底部色 | 更深的蓝黑 ~(8, 10, 25) | (30, 30, 50) |
| 整体 | 非常暗，液体和玻璃在暗背景上突出 | 底部偏亮 |

**关键差异**：参考图背景更暗，底部不该比顶部亮。

## 2. 颜色方案

### 2.1 液体颜色

参考图的颜色饱和度高、偏暖、厚重。对比分析：

| 颜色 | 参考图 RGB (估) | 当前值 | 建议值 | 说明 |
|------|----------------|--------|--------|------|
| 红 | (200, 45, 35) | (220, 60, 60) | **(205, 45, 40)** | 更深沉的暗红，减少粉感 |
| 蓝 | (30, 80, 210) | (60, 120, 220) | **(35, 85, 215)** | 更纯的宝蓝色，减少灰度 |
| 绿 | (100, 150, 20) | (60, 180, 80) | **(110, 155, 25)** | 橄榄绿/黄绿色，不是翠绿 |
| 黄 | (235, 180, 25) | (240, 200, 40) | **(240, 185, 25)** | 更偏金色/琥珀色 |
| 橙 | (225, 120, 25) | (240, 140, 40) | **(230, 120, 25)** | 更深沉的暖橙 |
| 紫 | (130, 55, 175) | (160, 80, 200) | **(135, 55, 180)** | 更深的皇家紫 |
| 青 | (25, 170, 180) | (40, 200, 200) | **(30, 170, 185)** | 更深沉的青色 |
| 粉 | (210, 95, 130) | (240, 120, 160) | **(215, 95, 135)** | 更偏玫红 |

**总体趋势**：降低明度约 10~15%，提高饱和度，颜色更厚重浓郁。

### 2.2 背景色

```lua
-- 参考图背景：从深蓝渐变到更深蓝黑
topColor    = { 12, 15, 35 }   -- 深海军蓝
bottomColor = {  8, 10, 25 }   -- 更深蓝黑
```

## 3. 几何参数建议

### 3.1 Config.TUBE 调整

```lua
Config.TUBE = {
    tubeWidth       = 50,       -- 60→50：略窄，更修长
    wallThickness   = 3,        -- 4→3：更薄的管壁
    slotHeight      = 55,       -- 40→55：每格更高，管身大幅拉长
    bottomSlotRatio = 0.75,     -- 0.8→0.75：球底略多承担
    topPadding      = 15,       -- 10→15：管口更通透
    ballHeight      = 28,       -- 25→28：更饱满的半球底
    ellipticity     = 0.30,     -- 0.35→0.30：椭圆略窄
    liquidAlpha     = 240,      -- 210→240：更不透明
    gap             = 14,       -- 20→14：管间距更紧凑
}
```

### 3.2 视觉对比

| 参数 | 当前 | 建议 | 效果 |
|------|------|------|------|
| 总高 (4格) | ~220px | ~310px | 管身拉长 41% |
| 宽高比 | 1:3.7 | 1:6.2 | 更接近参考图的修长比例 |
| 7管总宽 | 7×60+6×20=540px | 7×50+6×14=434px | 更紧凑，屏幕利用率更好 |

## 4. 渲染参数建议

### 4.1 玻璃管壁 (glass)

```lua
glass = {
    mainHighlightAlpha  = 55,     -- 28→55：主高光大幅增强
    secHighlightAlpha   = 20,     -- 10→20：次高光增强
    edgeDarkAlpha       = 28,     -- 12→28：边缘暗线更明显
    ballHighlightAlpha  = 38,     -- 22→38：球底高光增强
    ballHighlightSize   = 0.35,   -- 0.3→0.35：高光范围略大
    rimRingAlpha        = 45,     -- 30→45：管口厚度环更明显
}
```

### 4.2 液体着色 (liquid)

```lua
liquid = {
    edgeDarkAlpha       = 58,     -- 40→58：边缘暗化大幅增强
    edgeWidth           = 0.22,   -- 0.20→0.22：暗化区域略宽
    highlightAlpha      = 42,     -- 25→42：液体高光带增强
    highlightWidth      = 0.10,   -- 0.08→0.10：高光带略宽
    highlightPos        = 0.20,   -- 0.22→0.20：高光带略偏左
    surfaceRingAlpha    = 55,     -- 50→55：液面描边环增强
    surfaceSpotAlpha    = 70,     -- 60→70：液面光斑增强
    surfaceSpotSize     = 0.18,   -- 0.15→0.18：光斑略大
}
```

### 4.3 环境光遮蔽 (ao)

```lua
ao = {
    rimShadowHeight     = 8,      -- 5→8：管口内沿 AO 更深
    rimShadowAlpha      = 75,     -- 60→75：AO 更强
    ballJointAlpha      = 50,     -- 40→50：球底交汇处 AO 增强
    ballJointHeight     = 4,      -- 3→4：略高
}
```

### 4.4 背景渐变

```lua
-- drawBackground 中的渐变色：
topColor    = nvgRGBA(12, 15, 35, 255)    -- 当前 (15, 15, 30)
bottomColor = nvgRGBA(8, 10, 25, 255)     -- 当前 (30, 30, 50)
```

## 5. 新增渲染层：管壁蓝色调底色

参考图的玻璃管壁有明显的**蓝色调半透明底色**，当前实现缺少这一层。

### 方案

在 `_drawGlassWall` 中，所有渐变叠加之前，先填充一层淡蓝色半透明底色：

```lua
-- 管壁蓝色调底色（新增层）
nvgBeginPath(vg)
TubeRenderer._tubeOutlinePath(vg, ...)
nvgFillColor(vg, nvgRGBA(40, 60, 100, 18))  -- 淡蓝色调
nvgFill(vg)
```

### 参数

```lua
glass = {
    -- ...现有参数...
    baseTintColor  = { 40, 60, 100 },   -- 管壁蓝色调
    baseTintAlpha  = 18,                 -- 底色透明度（极淡）
}
```

## 6. 优先级与实施建议

### 第一批（视觉冲击最大）

| 序号 | 改动 | 工作量 | 效果 |
|------|------|--------|------|
| 1 | 颜色方案替换 (§2.1) | 改 Config 数值 | 颜色更厚重浓郁 |
| 2 | 几何参数调整 (§3.1) | 改 Config 数值 | 管身修长化 |
| 3 | 背景色加深 (§4.4) | 改 drawBackground 数值 | 整体氛围更沉稳 |

### 第二批（3D 质感增强）

| 序号 | 改动 | 工作量 | 效果 |
|------|------|--------|------|
| 4 | 玻璃高光增强 (§4.1) | 改 Config 数值 | 管壁更亮更透 |
| 5 | 液体着色增强 (§4.2) | 改 Config 数值 | 液柱圆柱感更强 |
| 6 | AO 增强 (§4.3) | 改 Config 数值 | 深度感增强 |
| 7 | 管壁蓝色调底色 (§5) | 新增渲染层 | 玻璃材质更真实 |

### 第三批（精细调整）

根据第一、二批实施后的实际视觉效果，微调各参数值。
